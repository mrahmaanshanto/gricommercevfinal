Platform core · Architecture

How a request reaches a module

One resolver, one identity layer and one entitlement check sit in front of every module. Stack stays Laravel and Next.js on the existing codebase.

Request lifecycle

Every entry point passes the same four checks

Web requests, API calls, webhooks, queued jobs and scheduled tasks all resolve a tenant before anything else runs. A check that fails stops the request with a clear screen, never a wrong store.

Core data model

About thirty new tables, in five groups

Everything the core adds lives beside the module tables, not inside them. Module tables only gain the tenant key.
