# Eight reference stores → eight GridCommerce themes (research, 16 Oct 2026)

The owner picked eight Bangladeshi stores as the looks merchants should be able to choose. Each GridCommerce theme takes
the **layout, sections and styles** of one store. It never copies their logo, photos, banner artwork, text or exact brand
colours; it uses its own name (close to theirs so the team can tell which is which) and the shop's own products.

| Theme | Reference | Kind of shop | Feel |
|---|---|---|---|
| **Ghorer Haat** | ghorerbazar.com | Grocery, honey, oil, dates | Cream page, orange accent, dark nav bar, Open Sans |
| **TechStar** | startech.com.bd | Big computer / electronics catalogue | Dark navy header, white mega nav, purple save pills, dense |
| **Natura** | naturobd.com | Natural / herbal / honey | Dark green header, gold buttons, soft-green and cream bands |
| **Trend Bazar** | htbazar.com | Trending home and gadget items | Violet brand, edge-to-edge carousels, outline buttons |
| **Shajghor** | shop.shajgoj.com | Beauty and cosmetics (banner-led) | White, pink accent, colour pill menu items, poster tiles |
| **Beauty Box** | beautybooth.com.bd | Beauty (K-beauty, bundles) | White, pink gradient buttons, chip nav, coupons, video reels |
| **Shei Gadget** | sheitech.com.bd | Gadgets and accessories | Black header, red accent, cards with red pill headings |
| **Gad Studio** | gadstyle.com | Gadgets and home appliances | Light grey page, white panels, navy flash-deal panel, coupons |

## 4. Product page
- **Ghorer Haat:** thumbs left; Add to cart + Buy now + Order on WhatsApp + Call for order (2 × 2); brand chip; pill tabs.
- **TechStar:** share / save / compare bar; info pills (price, regular, status, code, brand); key features + View more;
  points badge; variant chips with "required" check; **payment option cards (cash price vs EMI per month)**; spec table
  grouped by heading; tabs Specification · Description · Questions (n) · Reviews (n); similar products side list.
- **Natura:** size cards each with its own discount; outline Add to cart + Order now; WhatsApp order + Call with number;
  consultation button.
- **Trend Bazar:** vertical thumb slider; short description; filled qty + Add to cart; Order now full width; accordions
  with icons (Details, Delivery & returns, Reviews, Share); "More products" side list.
- **Shajghor:** size line; Save ৳ + % badge; **best-seller rank badges**; free-shipping box; app promo; wishlist square +
  Add to cart; **"Only 5 left"**; key–value brief description.
- **Beauty Box:** **sale countdown bar**; return-policy link; stock tag; gradient Add to bag; **bundle contents with
  expiry**; trust grid; wishlist and share on the photo.
- **Shei Gadget:** previous / next product; brand logo; variation chips; colour dots; warranty chip; Add to cart + Buy now;
  share + copy link.
- **Gad Studio:** "Price" tag; **"Spend ৳x more to get ৳100 off"**; corporate / bulk order box with WhatsApp; accordions;
  "More from this brand".

## 5. Checkout (speed = clicks and required fields from product to order)
| Theme | Style | Required fields | Notes |
|---|---|---|---|
| Natura | **Pop-up**, cash on delivery | 3 + delivery zone | Zone as 3 radio cards (inside city / outside / other district); **order bump**; total on the button; "we will call to confirm" — fastest |
| Shei Gadget | Page; Buy now opens it directly | 4 | Notice bar; district sets the delivery charge; COD, online, **COD with ৳200 bKash / Nagad advance + transaction ID**; terms |
| Ghorer Haat | Page | 4 (+ optional thana) | Login / register bar but guest is fine; order review with qty; payment as icon cards; coupon fold; notes |
| Shajghor | Page, compact | 5 | Two-column small fields; free-delivery note; COD, bKash, card / wallet, Upay; no item list |
| Gad Studio | Page with 3 steps | 4 | "Secure checkout"; **Full payment / Pay ৳200 advance** switch with due amount; tip cards; Pay with bKash; trust strip |
| TechStar | Page via "added to cart" pop-up | 7 | Points banner; payment card (COD, online, POS on delivery) + **delivery card (home, store pickup, express)**; coupon / gift voucher tabs |
| Beauty Box | **Sign in first** (phone +88 and code, or Google / Facebook) | — | Then checkout; slowest for first-time buyers |
