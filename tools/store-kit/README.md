# Store kit tools

A store kit (`<name>.gcstore.json`) is a whole store design in one file. It holds:

- theme settings
- headers
- page layouts
- HTML blocks
- menus with mega menus
- sample pages
- store notices
- block placements

It never holds products, customers or orders, so the same kit can be applied to any shop.

| File | What it is |
| --- | --- |
| `check.mjs` | Checks kits and prints plain-word errors and warnings. `--vocab` prints every allowed value. |
| `render.mjs` | Loads a kit into a fresh browser on a running app and saves screenshots: Home, category, product, search, cart and pages, on computer and phone. |
| `VOCAB.md` | Every allowed value, generated by `check.mjs --vocab`. |
| `SKILL.md` | How Claude builds a kit from a brief (the design service and new themes). |
| `src/lib/storefront/kits/` | Signal, Nokshi and Counter as kits. |

```
node tools/store-kit/check.mjs src/lib/storefront/kits/*.gcstore.json
node tools/store-kit/check.mjs --vocab > tools/store-kit/VOCAB.md
node tools/store-kit/render.mjs my-shop.gcstore.json --url http://localhost:3000 --out kit-shots
```

The rules live in the app itself, so the editors, the import screen and these tools can never disagree:

- `src/lib/storefront/schema.js`: every option, element, section, block kind, link type, notice place and spot.
- `src/lib/storefront/kit.js`: the format, `checkKit`, kit ⇄ store conversion and the shop-detail tokens.
- `src/lib/storefront/kitStore.js`: export and import in the app (restore point first).

## Rules for new options and themes

- **New option, element, section type or field:** add it to `schema.js`. The editors, the checker and VOCAB.md all
  pick it up. Then regenerate VOCAB.md.
- **New theme:** make it a kit, never code. It goes into super admin › Storefront themes, and shops import it from
  Online Store › Theme.

The checker needs Node 22.12 or newer. The renderer needs Playwright and Chromium.
